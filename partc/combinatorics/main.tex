  \block{Chains, antichains, shadows}{
    Noting that a complete matching of a bipartite graph from $X$ to $Y$ is a vertex disjoint collection of edges such that we cover $X$.

    \begin{theorem}[Hall's theorem]
    \ $G = (X \cup Y, E)$ a bipartite graph has a complete matching from $X$ to $Y$ if and only if for all $S \subseteq X$, $|\Gamma(S)| \ge |S|$.
    \end{theorem}
    \hphantom{}

    We then claim that there is a partition of $\mathcal{P}(n)$ into ${n \choose \floor{n/2}}$ chains, following as we can find matchings from layer to layer when viewed as $Q_n$, and there are ${n \choose \floor{n/2}}$ elements in the centre allowing us to choose that number of such chains through the layers. Thus we can then prove Sperner's lemma: \\

    \begin{theorem}[Sperner's lemma]
    \ An antichain in $\mathcal{P}(n)$ has size at most ${n \choose \floor{n/2}}$.
    \end{theorem}
    \hphantom{}

    This is clear as a chain and an antichain meet on at most one element, so partitioning $\mathcal{P}(n)$ into some number of chains means having an antichain with more elements would mean it shares two elements with a chain. \\

    \begin{theorem}[LYM Inequality]
    \ Let $\mc{F} \subseteq \mc{P}(n)$ be an antichain. Then
    \begin{align*}
      \sum_{i=0}^n \frac{|\mc{F} \cap [n]^{(i)}|}{{n \choose i}} \le 1,
    \end{align*}
    and we have equality iff $\mathcal{F} = [n]^{(i)}$ for some $i \in [n]$.
    \end{theorem}
    \hphantom{}

    \begin{definition}
    \ With $\mathcal{F} \subseteq X^{(k)}$ a $k$-uniform family on $X$, the lower shadow $\partial \mc{F}$ of $\mc{F}$ is $\displaystyle \bigcup_{A \in \mc{F}} A^{(k-1)}$.
    \end{definition}
    \hphantom{}

    Essentially, to form a shadow on a $k$-uniform family $\mc{F}$, from each $A \in \mc{F}$ we pick $k-1$ elements. \\

    This is proven using a local version with $\mathcal{F} \subseteq [n]^{(r)}$, that
    \begin{align*}
      {n \choose r} |\partial \mc{F}| \ge {n \choose r-1} |\mc{F}|,
    \end{align*}
    shown via double counting of edges in $Q_n$, noting that each element in $\mathcal{F}$ contains $k$ sets of size $k-1$, and each element in $\partial \mathcal{F}$ is contained by $\le n - (k-1)$ elements in $\mathcal{F}$, so $(n - k + 1) |\partial \mc{F}| \ge k |\mc{F}|$. Equality occurs $\mc{F} = [n]^{(k)}$ or $\mc{F} = \varnothing$. \\

    As a result, if $\mc{F}$ is an antichain in $\mc{P}(n)$, $|\mc{F}| \le {n \choose \floor{n/2}}$ with equality for $\mc{F} = [n]^{(k)}$, $k \in \{\floor{n/2}, \ceil{n/2}\}$. \\

    These results can also all be shown probabilistically. If we take a random set in $\mc{P}(n)$, then the LHS of the LYM inequality is just the probability that this random set is in $\mc{F}$. \\

    \begin{theorem}[Dilworth's theorem]
    \ Let $(P, \le)$ be a finite poset. The minimum number of chains needed to cover $P$ is the maximum size of an antichain.
    \end{theorem}
    \hphantom{}

    One direction of this is clear: the minimum number of chains needed to cover $P$ is certainly not less than the maximum size of an antichain, because then we would have an antichain of maximum size which contains more than one element in one of the covering chains, giving a contradiction. \\

    The other direction is slightly more difficult, but the key idea is to provide a construction of a chain covering which is of equal size as the largest antichain. Drawing a picture, this looks possible but fiddly for large $|P|$, and thus we opt for strong induction. Our goal is to find a proper decomposition of $P$ that will give us chain coverings by induction, and we hope to use these to construct the covering of $P$. In particular, we want to decompose $P$ \emph{vertically}, cutting it along an antichain, so that we might then link up the chains after decomposition. \\

    Labelling an antichain of maximum size $A$, we consider first the case that we can just decompose $P$ by taking a maximal chain $C$. If $P \setminus C$ contains no antichain of size $|A|$, then it may be covered by $|A|-1$ chains, and thus we are done. Otherwise, we split $P$ into $S^+ = \bigcup_{a \in A} \{x : x \ge a\}$ and $S^- = \bigcup_{a \in A} \{x : x \le a\}$, and may argue that these are each proper subsets, as the maximal and minimal elements of $C$ evade each of them. \\

    We also note a dual to this theorem:
    \begin{theorem}[Mirsky's theorem]
    \ Let $(P, \le)$ be a finite poset. The minimum number of antichains needed to cover $P$ is the maximum size of a chain.
    \end{theorem}
    \hphantom{}

    To prove this, we calculate the height of a maximal chain starting at each element $v \in P$, and note that we can get antichains by selecting the elements with a particular height, for each possible height. \\

    \begin{theorem}[Erd\"{o}s]
    \ With $\bm{x} \in \mathbb{R}^n$ s.t. $x_i \ge 1$ for all $i \in [n]$. For every $\alpha \in \mathbb{R}$, there are at most ${n \choose \floor{n/2}}$ subsets $I \subseteq [n]$ such that $\sum_{i \in I} x_i \in \rightopen{\alpha}{\alpha+1}$.
    \end{theorem}
    \hphantom{}

    By using Sperner's lemma, we see that if more such subsets existed, we would have one containing the other, and thus violating the required property. \\

    Indeed we can extend this theorem to the case $|x_i| \ge 1$, noting that replacing $+x_i$ with $-x_i$ just switches around whether we're making an `include' or `don't include' decision, translating the collection of possible sums. \\

    We want to generalise this a bit more, and in order to do this we introduce the concept of chain symmetry -- we say that a chain in $\mc{P}(n)$ is symmetric if each link adds one element, and if the smallest and largest sets in the chain have gross cardinality $n$. Indeed we can partition $\mc{P}(n)$ into symmetric chains by induction. Critically, as every symmetric chain must contain an element in $[n]^{(\floor{n/2})}$, thus there are ${n \choose \floor{n/2}}$ chains in such a decomposition.\\

    \begin{theorem}[General dimension Erd\"os]
    \ Let $k, n \ge 1$, suppose that $\bm{X} = [\bm{x}_1, \dots, \bm{x}_n] \in \mathbb{R}^{k \times n}$ s.t. $||\bm{x}_i ||_2 \ge 1$ for all $i$. With $K \subseteq \mathbb{R}^k$ s.t. $\mathrm{diam}(K) < 1$, there are at most ${n \choose \floor{n/2}}$ subsets $I \subseteq [n]$ s.t. $\sum_{i \in I} x_i \in K$.
    \end{theorem}
    \hphantom{}

    It is sufficient to show that we can partition $\mc{P}(n)$ into ${n \choose \floor{n/2}}$ sets $D_1, \dots, D_{n \choose \floor{n/2}}$ which are `sparse', meaning that for $A, B \in D_i$, $|| \sum_{i \in A} \bm{x}_i - \sum_{j \in B} \bm{x}_j || \ge 1$. If such a partition exists then we must only be able to select one valid set from each collection in the partition, and the result is proven. \\

    To prove this, we find a symmetric partition $\mc{P}(n)$ into sparse families by induction. For a symmetric partition $\mc{F}_1, \dots, \mc{F}_m$, order the elements of $\mc{F}_i$ as $A_1, \dots, A_t$ where $\langle x_{A_1}, x_n \rangle \le \dots \langle x_{A_t}, x_n \rangle$, and we hope to then generate new chains for which the sets more aligned with $x_n$ are at the top (and thus $x_n + x_{A_t}$ is kept far from the other sets). We do this and find straightforwardly that with the same procedure to generate a symmetric partition in the first place subject to this particular reordering, we get the desired result. \\


    \innerblock{Kruskal-Katona}{
    We would like to get a more precise understanding of the relative cardinalities of $r$-uniform sets and their shadows. We get an immediate inequality via LYM (that the density of a shadow in $[n]^{(r-1)}$ is greater than the density of the original set in $[n]^{(r)}$), but want to understand where we get closer to and further from the equality. To do this, we define lexicographic and colexicographic order: \\

    In \emph{lex}, for $A, B \in [n]^{(r)}$, $A <_{\mathrm{lex}} B$ if $A \neq B$ and $\min(A \triangle B) \in A$. Thus in lex order, the place of a set in an order is primarily determined by its lowest element (and then its next lowest, and on and on). We therefore get in $r = 3$,
    \begin{align*}
      123,\,124,\,125,\,\dots,\,12(n),\,134,\,135,\,\dots,1(n-1)(n), 234, \dots.
    \end{align*}
    To compute the successor of $A = \{a_1, \dots, a_r\}$ written in order, increment the largest $i$ such that $a_i < n+r-i$, and then reset each $a_j$ to its smallest possible value for $j > i$. \\

    In \emph{colex}, for $A, B \in [n]^{(r)}$, $A <_{\mathrm{colex}} B$ if $A \neq B$ and $\max(A \triangle B) \in B$. Thus in colex order, the place of a set in an order is primarily determined by its highest element (and then its next highest, and on and on). Thus in $r = 3$,
    \begin{align*}
      123,\,124,\,134,\,234,\,125,\,135,\,235,\,145,\,245,\,345,\,\dots.
    \end{align*}
    Crucially, we get a concentration of the same numbers in a way not seen in lex, ensuring that the possible shadows created in any prefix in colex order ends up being small. Note that for a particular set $A = \{a_1, \dots, a_r\}$ written in order, we can compute the successor of $A$ by incrementing the first $a_i$ such that $a_i + 1 < a_{i + 1}$, and resetting all $a_j$ to $j$ for $j < i$. \\

    Colex may be said to be dual to lex. If we write $\mathrm{lex}, \mathrm{colex} : [n]^{(r)} \to [{n \choose r}]$ for the index of each element under each ordering, we see that
    \begin{align*}
      \left(x \mapsto {n \choose r} + 1 - x\right) \circ \mathrm{colex} = \mathrm{lex} \circ (x \mapsto n+1 - x)
    \end{align*}
    To see this, note that $A <_{\mathrm{colex}} B$ iff $A \neq B$ and $\max(A \triangle B) \in B$, which is equivalent to $\min((n+1-A) \triangle (n+1-B)) \in n+1-B$, and this in itself equivalent to $n+1-A >_{\mathrm{lex}} n+1-B$. Thus colex order is equivalent to reversed lex order on the reversed order on $[n]$, giving us our duality relation. If we have intuitively that colex gives a concentrated ordering while lex gives a sparse ordering, then this explains it: if we don't care about the underlying symbol set, lex is just reversed colex, and thus as sparse as colex is concentrated. \\

    Helpfully, we see that the weight of a particular element in colex can be quantified straightforwardly:
    \begin{align*}
      w_{\mathrm{colex}}(A) = \sum_{i \in A} 2^i.
    \end{align*}
    The idea here being that each consecutively $2^i$ term will dominate over any sum of $2^j$s for $j < i$, so $w_{\mathrm{colex}}(A) < w_{\mathrm{colex}}(B)$ iff the largest $i$ on which the two sets differ occurs in $B$. Using duality, we can get the slightly less natural, but still valid expression
    \begin{align*}
      w_{\mathrm{lex}}(A) = 1 - \sum_{i \in A} 2^{-i}.
    \end{align*}
    In this case it is the low-value terms which dominate the sum, pushing it towards the front. \\

    Kruskal-Katona gives us a language for this notion of `concentratedness'. \\

    \begin{theorem}[Kruskal-Katona]
    \ Let $\mc{F} \subseteq [n]^{(r)}$, $\mc{A}$ be the family of the first $|\mc{F}|$ elements of $[n]^{(r)}$ in colex order. Then $|\partial \mc{F}| \ge |\partial \mc{A}|$.
    \end{theorem}
    \hphantom{}

    Essentially, the claim is that colex order creates the most overlap in the shadow, thus minimising its size. To show this takes some time, but fundamentally we do this by reducing $\mc{F}$ to a family which is an initial segment of colex, and demonstrate that at each step $|\partial \mc{F}'| \le |\partial \mc{F}|$. Intuitively, our goal is to swap large elements for small elements, to get ourselves towards colex. \\

    We define a compression operator to swap in $i$ instead of $j$ and $j$ instead of $i$ wherever this is coherent, and to leave all other sets in $\mc{F}$ untouched otherwise. We refer to this as a left compression where $i < j$, and conjecture that left compressions should not increase the shadow.
    \begin{align*}
      C_{ij}(A) &= \begin{cases}
        (A \setminus j) \cup i & \text{if }i \not\in A, j \in A \\
        A & \text{otherwise}
                 \end{cases} \\
      C_{ij}(\mc{F}) &= \{C_{ij}(A) : A \in \mc{F}\} \cup \{A \in \mc{F} : C_{ij}(A) \in \mc{F}\}.
    \end{align*}

    Indeed, the shadow of $C_{ij}(\mathcal{F})$ is no larger than the shadow of $\mc{F}$, and there is a family $\mc{A}$ which is a fixed point of all left-compressions (which we call left-compressed). Unfortunately, not every left-compressed family is in colex form, as $\{12, 13, 14\}$ is left-compressed but contains $14$, which we can't get rid of e.g. via $C_{34}$ because we get it back from $13$. Indeed we want to be able to convert this into $\{12, 13, 23\}$, but this is impossible without doing two steps simultaneously. \\

    Thus we want to replace $i$ and $j$ with disjoint sets $U, V \in \mc{P}(n)$, $|U| = |V|$, and technical details allow us to get the compression as desired. \\

    We write
    \begin{align*}
      C_{UV}(A) &:= \begin{cases}
        (A \setminus V) \cup U & \text{if } U \cap A = \varnothing, V \subseteq A \\
        A & \text{otherwise.}
      \end{cases} \\
      C_{UV}(\mc{F}) &:= \{C_{UV}(A) : A \in \mc{F}, C_{UV}(A) \not\in \mc{F}\} \cup \{A : A \in \mc{F}, C_{UV}(A) \in \mc{F}\}.
    \end{align*}
    Note that (in the sense of the operator defined on $\mc{P}(n)$) $C_{UV} \circ C_{UV} = C_{UV}$, making this description equivalent to the one presented in the lecture notes. We see that this is essentially a `replace $V$ with $U$ whenever this is clean' operator, and so the operator on $\mc{P}(\mc{P}(n))$ is defined to replace each set by the swapped set whenever it creates something new. \\

    Our concern is specifically how this deals with shadows. We claim in particular that if for any $u \in U$, there is $v \in V$ such that $\mc{F}$ is $(U \setminus u, V \setminus v)$ compressed, then $|\partial C_{UV}(\mc{F})| \le |\partial \mc{F}|$, with the idea being that $C_{VU}(\partial C_{UV}(\mc{F}) \setminus \partial \mc{F}) = \partial \mc{F} \setminus \partial C_{UV}(\mc{F})$, and is injective. \\

    Once this is clear, we argue that if $\mc{A}$ is of minimal colex weight subject to $|\mc{A}| = |\mc{F}|$, $|\partial \mc{A}| \le |\partial \mc{F}|$, then $\mc{A}$ is an initial segment of colex. To do this, look at its compression via
    \begin{align*}
    \Lambda = \{(U, V) : |U| = |V| > 0, U \cap V = \varnothing, \max U < \max V\}.
    \end{align*}
    Either it is already $\Lambda$ compressed in which case it can be seen that it is an initial segment of colex, and if it is not then using the above lemma applied to a minimal size $U$ (which can only exist if the set of $(U, V)$ for which $\mc{A}$ is not compressed is non-empty), we get a contradiction.
    }

  \block{Intersections}{
    We say that $\mc{A} \subseteq \mc{P}(n)$ is intersecting if $A \cap B \neq 0$ for $A, B \in \mc{A}$. It's immediately clear that $|\mc{A}| \le 2^{n-1}$. \\

    \begin{theorem}[Erd\"{o}s-Ko-Rado]
    \ For $r \le n/2$, $\mc{A} \subseteq [n]^{(r)}$ intersecting implies that $|\mc{A}| \le {n-1 \choose r-1}$.
    \end{theorem}
    \hphantom{}

    There are two separate proofs for this: the first involves Katona's circle method, and the second using the Kruskal-Katona theorem. The circle method idea is to double count, by counting the number of edges in the corresponding bipartite graph, the number of pairs $(f, A)$ where $f : [n] \to [n]$ is a bijection, $A \in \mc{A}$, and $f(A)$ is a contiguous sequence modulo $n$ (so allowing $n \to 1$ as a step in the interval). Double counting allows us to get an upper bound on the number of $A$s for each $f$, and a lower bound on the number of $f$s for each $A$, giving the desired result. \\

    The Kruskal-Katona idea is to instead think in terms of shadows -- noting that any shadow (and indeed repeated shadow) of $\{A^c \in [n]^{(n-r)} : A \in \mc{A}\}$ is disjoint from all sets in $\mc{A}$, and thus we can use Kruskal-Katona to get a lower bound on the size of these shadows. \\

    \innerblock{Application of EKR}{
    \begin{theorem}[Liggett's theorem]
    \ With $\bm{Y} \overset{\mathrm{i.i.d.}}{\sim} \mathrm{Ber}(p)^n$, $\bm{\alpha} \ge 0$, $\sum \alpha_i = 1$,
    \begin{align*}
      \P\left(\sum_i \alpha_i Y_i \ge 1/2\right) \ge p.
    \end{align*}
    \end{theorem}
    \hphantom{}

    This theorem is proven only in the case where for no $I \subseteq [n]$ do we have $\sum_{i \in I} \alpha_i = 1/2$. The idea will be to track $\sum Y_i \sim \mathrm{Bin}(n, p)$, and deterministically calculate the number of `satisfying' instances for each value of $\sum Y_i$. The key facts are then that with $\mc{A}_k = \{A \in [n]^{(k)} : \sum_{i \in A} \alpha_i > 1/2\}$, $|\mc{A}_k| + |\mc{A}_{n-k}| = {n \choose k}$ by taking the complement, and that $\mc{A}_k$ must be intersecting for each $k$. We then want to apply EKR to $\mc{A}_{n-k}$ for $k \ge n/2$, thus demonstrating that many instances are satisfactory for large $k$, and that this overcomes the issues for low $k$.
    }
    \hphantom{}

    \begin{theorem}[Two Families Theorem]
    \ Let $A_1, \dots, A_k$, $B_1, \dots, B_k$ be finite sets such that each $(A_i, B_i)$ pair is disjoint, but no other $(A_i, B_j)$ pair is disjoint. Then
    \begin{align*}
      \sum_{i=1}^k {|A_i| + |B_i| \choose |A_i|}^{-1} \le 1.
    \end{align*}
    \end{theorem}
    \hphantom{}

    Observe immediately that each summand is equal to the probability that we choose the $(A_i, B_i)$ partition of $A_i \cup B_i$. In this case, the joint distribution on our choices for each $i$ is specified by selecting, uniformly, an ordering on the elements of all sets, and then determining the probability that all elements of each $A_i$ occur before their corresponding $B_i$. \\


      \begin{theorem}[Kleitman's theorem / Harris lemma]
      \ Let $\mc{A}, \mc{B} \subseteq \mc{P}(n)$ be down-sets. Then
      \begin{align*}
        |\mc{A} \cap \mc{B}| \ge 2^{-n}|\mc{A}||\mc{B}|
      \end{align*}
    \end{theorem}

    This may be proven by standard techniques with induction on $n$. The intuition for this should be that $|\mc{A} \cap \mc{B}| / 2^n \ge |\mc{A}|/2^n \cdot |\mc{B}| / 2^n$, and thus that down-sets must intersect considerably (in particular, that if we include each element in $[n]$ with probability $1/2$, $\mu(A \cap B) \ge \mu(A)\mu(B)$). This has an important application in problem sheet 3, and more generally has applications wherever we want to bound the cardinality of families which are likely to agree considerably due to intersection properties. \\

    Note that this comes with an immediate (unless you're me, panicking 5 minutes into a probabilistic combinatorics paper, apparently) corollary for up-sets. For any down-set $\mc{A}$, assume that $C \supseteq B \not\in \mc{A}$. Then if $C \in \mc{A}$, thus $B \in \mc{A}$ which is a contradiction, so clearly $\mc{A}^c$ is an up-set. Therefore, for $\mc{A}$ a down-set, $\mc{C}$ an up-set, 
    \begin{align*}
      |\mc{A} \cap \mc{C}| &= |\mc{A}| - |\mc{A} \cap \mc{C}^c| \\
                           &\le |\mc{A}| - 2^{-n}|\mc{A}| |\mc{C}^c| \\
      &= |\mc{A}|(1-n2^{-n}) + 2^{-n} |\mc{A}| |\mc{C}| \\
&\le 2^{-n}|\mc{A}| |\mc{C}|
    \end{align*}
    where we can see the case separately for $n = 1$. \\

    \begin{definition}
    \ $\mc{A} \subseteq \mc{P}(n)$ is $t$-intersecting if $|A \cap B| \ge t$ for all $A, B \in \mc{A}$.
    \end{definition}
    \hphantom{}

    \begin{theorem}[Generalised Erd\"os-Ko-Rado]
      With $1 < t \le k$ integers, there is an integer $n_0$ such that for $n > n_0$, $\mc{A} \subseteq [n]^{(k)}$ is $t$-intersecting implies
      \begin{align*}
        |\mc{A}| \le {n-t \choose k-t}
      \end{align*}
      with equality iff $\mc{A} = \{A \in [n]^{(k)} : T \subseteq A\}$ for some $T \in [n]^{(t)}$.
    \end{theorem}
    \hphantom{}

    This isn't \emph{quite} a full generalisation due to the ``for large enough $n$'' condition, but its proof is comparatively simple. The point of this is to give us even stronger bounds on sets which we know are `very intersecting'. \\

    The argument is a case distinction with respect to $A, B \in \mc{A}$ for which $|A \cap B| = t$.
    \begin{itemize}
            \item[] \textbf{Sunflower: } for all $C \in \mc{A}$, $A \cap B \subseteq C$, and so the number of possible sets is exactly ${n - t \choose k - t}$.
      \item[] \textbf{Semi-sunflower: } there exists $C \in \mc{A}$ such that $A \cap B \not\subseteq C$. Thus every $D \in \mc{A}$ must intersect $A \cup B \cup C$ on $\ge t+1$ elements (otherwise it fails to be $t$-intersecting on $A$, $B$, or $C$). Thus there exists at most ${|A \cup B \cup C| \choose t+1} {n-t-1 \choose k-t-1}$ sets satisfying this property in $\mc{A}$, and for $n$ large enough
            \begin{align*}
              {|A \cup B \cup C| \choose t+1} {n - t - 1 \choose k-t-1} &\le |A \cup B \cup C|^{t+1} (n-t-1)^{k-t-1} \\
                                                                        &\le (3k)^{t+1}n^{k - t - 1} \\
                                                                        &< \left(\frac{e(n-t)}{k-t}\right)^{k-t} \\
              &\le {n - t \choose k - t}
            \end{align*}
            where the third inequality holds for $n$ large enough by standard polynomial asymptotics.
    \end{itemize}
    \hphantom{}

    The equality result can be seen immediately, as it may hold only in the sunflower case. \\

    It turns out we get a distinctly tight bound when the sense of $t$-intersection is strict:
      \begin{theorem}[Fisher's inequality]
      \ Let $k \ge 1$. If $\mc{A} \subseteq \mc{P}(n)$ satisfies $|A \cap B| = k$ for all distinct $A, B \in \mc{A}$, then $|\mc{A}| \le n$.
      \end{theorem}
      \hphantom{}

      This follows from a new type of argument which we continue to use in this section: to identify sets with their characteristic function (a vector in $\mathbb{F}_2^n$), and then use properties of linear independent sets. In this case, we just argue that if $\mc{A} \subseteq [n]^{(> k)}$, then $\{\chi_A : A \in \mc{A}\}$ is linearly independent, which is obtained by looking at the inner product. \\

      \begin{theorem}[Oddtown theorem]
      \ Let $\mc{A} \subseteq \mc{P}(n)$ be a family such that $|A|$ is odd for $A \in \mc{A}$ and $|A \cap B|$ is even for all distinct $A, B \in \mc{A}$. Then $|\mc{A}| \le n$.
      \end{theorem}
      \hphantom{}

      This is done using exactly the same argument as above.\\

      \begin{theorem}[Modular Frankl-Wilson theorem]
        \ Let $p$ be prime, $S \subseteq \{0, 1, \dots, p-1\}$, and $\mc{A} \subseteq \mc{P}(n)$ satisfies
        \begin{itemize}
          \item $|A| \notin S \,\mathrm{mod}\, p$ for all $A \in \mc{A}$, and
          \item $|A \cap B| \in S \,\mathrm{mod}\, p$ for all $A, B \in \mc{A}$ distinct.
        \end{itemize}
        Then
        \begin{align*}
          |\mc{A}| \le \sum_{i=0}^{|S|} {n \choose i}.
        \end{align*}
      \end{theorem}

      The proof of this involves once again working in $\mathbb{F}_p^n$. For $A \in \mc{A}$, define
      \begin{align*}
        f_A(x) = \prod_{s \in S} \left(\sum_{i \in A} x_i - s\right)
      \end{align*}
      Now on the basis that we only want to evaluate our polynomials on characteristic vectors, we can `multilinearise' them, replacing each power $x^k$ by $x$, and restricting to $\mathbb{F}_2$, in order to squeeze down the dimension of the space within which we're working. We then get a set of linearly independent multilinear polynomials of degree at most $|S|$, and as this is spanned by the monomials $\{\prod_{i \in A} x_i : |A| \le |S|\}$, the result follows by the same principle just by calculating the dimension. \\

      \begin{theorem}[Frankl-Wilson theorem]
      \ Let $\mc{A} \subseteq \mc{P}(n)$ be $S$-intersecting (for $A, B \in \mc{A}$ distinct, $|A \cap B| \in S$). Then
      \begin{align*}
        |\mc{A}| \le \sum_{i=0}^{|S|} {n \choose i}
      \end{align*}
      \end{theorem}
      \hphantom{}

      A reduced form of this with the assumption $|A| \not\in S$ for $A \in \mc{A}$ is immediate from the above, and we don't prove the more general version. \\

      \begin{theorem}[Ray-Chaudhuri-Wilson]
        \ Let $\mc{A} \subseteq [n]^{(k)}$ be $S$-intersecting with $S \subseteq \{0, \dots, k-1\}$. Then
        \begin{align*}
          |\mc{A}| \le {n \choose |S|}.
        \end{align*}
      \end{theorem}
      \hphantom{}

      The proof of this requires performing the same polynomial linear independence argument, but also adding an additional $\sum_{i = 0}^{|S|-1} {n \choose i}$ elements to the spanning set. To do this, we use the functions for $B \in [n]^{(\le |S|-1)}$,
      \begin{align*}
        q_B(x) = \left(\sum_{i = 0}^n x_i - k\right) \prod_{i \in B} x_i.
      \end{align*}
      Note that $q_B(\chi_C) = 0$ if $B \not\subseteq C$ or $|C| = k$, and is non-zero otherwise. Thus we can apply the linear combination of this and the previous $f_A$ to the characteristics $\chi_A$ for $A \in \mc{A}$ to get the coefficients of the $f_A$s equal to zero, and then in increasing order to minimal $\chi_C$. This gives linear independence. \\

      To summarise the collection of theorems: \\

        \hline
        & $\mc{A} \subseteq$ & $|A \cap B| \in$ & $|A| \not\in$ & $\displaystyle |\mc{A}| \le$ \\

    From the above, we see that we have a collection of theorems for the general $\mc{A}$ case. Note that the Oddtown and Fisher cases are slightly better than special cases, as their argument allows us to remove constants from the vector space (thus decreasing the bound by $1$). We also have a few theorems for the $k$-uniform case, with the most general theorem being RCW. In practice we often just want to take the bound as a polynomial in $n$, so RCW is almost a total generalisation. \\

    \innerblock{Applications}{
      \begin{theorem}[Kahn-Kalai]
        \ Let $k(d)$ be the smallest integer such that every subset of $\mathbb{R}^d$ of diameter $1$ can be partitioned into $k(d)$ sets of smaller diameter. Then there is $c > 1$ such that
        \begin{align*}
          k(d) \ge c^{\sqrt{d}}
        \end{align*}
        for infinitely many $d$.
      \end{theorem}
      \hphantom{}

      Our overarching goal within this proof is to construct, with $d$ an increasing function of $p$, a set $K \subseteq \mathbb{R}^d$ corresponding to a set of graphs, such that if $L \subseteq K$ has a smaller diameter, by the nature of the identification the graph of $L$ takes up a bounded fraction of the graph of $K$ (which we can then use to bound below the number of such $L$s we need to divide $K$ up). \\

      To do this, take $d = {4p \choose 2}$, and with the natural identification of $\{0, 1\}^d$ with subsets of $E(K_{4p})$, write for $A \in [4p]^{(2p)}$, $E_A$ as the complete bipartite graph connecting $A$ and $A^c$, $\mc{F} := \{E_A : A \in [4p]^{(2p)}\}$. We then define our $K \subseteq \mathbb{R}^d$ as the natural identification of $\mc{F}$, and note that for $A, B \in [4p]^{(2p)}$, $||v_{E_A} - v_{E_B}||^2 = |E_A| + |E_B| - 2|E_A \cap E_B|$, so thus any $L \subseteq K$ with smaller diameter, for $A, B$ distinct in $\mc{A}$ the set of subgraphs corresponding to $L$, $|E_A \cap E_B|$ cannot be minimal (occurring iff $|A \cap B| = p$), and thus we get our result from the lemma, that
      \begin{align*}
        |\mc{F}|/|\mc{A}| &\ge \frac{1}{6}{4p \choose 2p}/{4p \choose p-1}
      \end{align*}
      and thus covering $K$ requires this number of sets, which one can see is asymptotically exponential in $p$, which is itself asymptotically equivalent to $\sqrt d$. \\

      \begin{lemma}
      \ Let $p$ be a prime and $\mc{A} \subseteq [4p]^{(2p)}$. If there is no distinct pair $A, B \in \mc{A}$ with $|A \cap B| = p$, then $|\mc{A}| \le 4{4p \choose p-1}$.
      \end{lemma}
      \hphantom{}

      Take $x \in [4p]$ which occurs in at least half the sets in $\mc{A}$ (see existence by a probabilistic argument). Note that for distinct $A, B \in \mc{A}$ both containing $x$, $|A \cap B| \in \{1, \dots, p-1\} \,\mathrm{mod}\, p$, and $|A| = 2p \not\in \{1, \dots, p-1\} \,\mathrm{mod}\, p$, so applying M-FW gives
      \begin{align*}
        \frac{1}{2}|\mc{A}| \le |\{A \in \mc{A} : x \in A\}| \le \sum_{i=0}^{p-1} {4p \choose i} \le 2{4p \choose p-1}
      \end{align*}
      where the last equality is from rearrangement with the inequality ${4p \choose i-1} \le {4p \choose i}/2$, and thus $|\mc{A}| \le 4{4p \choose p-1}$ (indeed we can also get $|\mc{A}| \le 3{4p \choose p-1}$ by the same method, but this is unnecessary).
    }

    \block{VC dimension and traces}{
      The point of VC dimension is to quantify, of a collection of subsets $\mc{F}$, what is the largest set of points such that $\mc{F}$ is rich enough to encode all binary classifications of them? It can be described as quantifying the complexity or richness of a set collection. \\

      This is a task well-studied by learning theory. In this context, the setup is that we want to understand the \emph{capacity} of a particular model for learning, specifically in the context of binary classification (where we want to learn a function $\widetilde{f} : X \to \{0, 1\}$, ideally such that it is equal to some unknown $f : X \to \{0, 1\}$). For a set $\mc{F} \subseteq \mc{P}(X)$, we define the \emph{model} as the collection of candidate classifiers (also known as the set of parametrisations)
      \begin{align*}
        \mc{C} := \{\chi_F : F \in \mc{F}\}.
      \end{align*}
      The learning model will then, for a particular task instance $f$, and some collection of training data $D = \{(x, f(x)) : x \in S\}$, attempt to find a solution $\widetilde{f} \in \mc{C}$ to minimise $\Vert f - \widetilde{f} \Vert$ (with some appropriate norm on $\{0, 1\}^X$). Clearly, if $\mc{F} = \mc{P}(X)$, then such a solution will always exist, although it will take being given all $2^{|X|}$ points to learn it (at which point there are no unknowns to predict!).\\

      The VC dimension of the model $\mc{C}$ is then the maximum size of a collection of training data $|D| = |S|$ such that for any $f \in \{0, 1\}^X$, there exists $\widetilde{f} \in \mc{C}$ such that $\widetilde{f}\big|_{S} \equiv \restr{f}{S}$. In English: it's the largest collection of data points which the model would always be able to learn to distinguish. If any more points were to be added, then \emph{a priori} the model could fail on the training set not because of limitations of the training procedure, but because it isn't sufficiently complex. \\

      We now give its technical definition, which can be seen to be equivalent to the one above for $\mc{C}$. \\

      \begin{definition}[Trace]
      \ For $\mc{F} \subseteq \mc{P}(X)$, $S \subseteq X$, the trace of $\mc{F}$ on $S$ is
      \begin{align*}
        \restr{\mc{F}}{S} := \{F \cap S : F \in \mc{F}\}
      \end{align*}
      and $\mathrm{tr}_{\mc{F}}(S) = \big|\restr{\mc{F}}{S}\big|$. \\

      We say that $S$ is shattered by $\mc{F}$ if $\restr{\mc{F}}{S} = \mc{P}(S)$, and define the VC dimension of $\mc{F}$ as
      \begin{align*}
        \max\{|S| : S \subseteq X \text{ is shattered by }\mc{F}\}.
      \end{align*}
      \end{definition}
      \hphantom{}

      To give some intuition: as a result of this, we're mainly concerned with being able to divide up a finite set $S$ of elements by the various sets in $\mc{F}$. For example, the VC-dimension of the set of half-spaces in $\mathbb{R}^2$ is 3, because it's not possible to draw 4 points on a plane without there being two lines between distinct pairs which intersect, and thus any half plane containing two of these opposite points must also contain their line, and thus the intersection, including a third point. \\

      \begin{theorem}[Shauer-Shelah]
      \ If $\mc{A} \subseteq \mc{P}(n)$ has VC dimension at most $d$,
      \begin{align*}
        |\mc{A}| \le \left|[n]^{(\le d)}\right|
      \end{align*}
      \end{theorem}

      The intuition is that to shatter a set in $[n]^{(d+1)}$, it's sufficient to just have $> \left|[n]^{(\le d)}\right|$ sets in your system, because at a certain point we have to capture at least one $[n]^{(d+1)}$ set fully. \\

      We may prove this either by induction on $n+d$ or by compression. The compression argument defines $\pi_i : \mc{P}(n) \to \mc{P}(n)$ for $i \in [n]$ by
      \begin{align*}
        \pi_i(\mc{C}) &= \{C \setminus \{i\} : C \in \mc{C},\, C \setminus \{i\} \not\in \mc{C}\} \cup \{C : C \in \mc{C},\, C \setminus \{i\} \in \mc{C} \}.
      \end{align*}
      That is, for each $C \in \mc{C}$, we replace it by $C \setminus \{i\}$ if this set doesn't already exist in $\mc{C}$. Thus $\pi_i(\mc{C}) = \mc{C}$ for all $i \in [n]$ iff $\mc{C}$ is a down-set, and as $\pi_i$ otherwise reduces the sum of the cardinalities of $\mc{C}$, this procedure terminates. \\

      The key property of this compression is that no set not shattered by $\mc{C}$ will be shattered by $\pi_i(\mc{C})$, so $\mathrm{VC}(\mc{C}) \ge \mathrm{VC}(\pi_i(\mc{C}))$. The intuition for this is that highly intersecting set systems may have traces with similarly high levels of intersection, ensuring that it may account for all of the problems in $\mc{P}(S)$. As we remove elements, we remove such intersections, and thus may decrease the system's VC dimension. \\

      Strictly, if $\mc{C}$ does not shatter $S$, then there exists $A \subseteq S$ such that for $C \in \mc{C}$, $C \cap S \neq A$. Thus the only sets in $\pi_i(\mc{C})$ which have a chance are the new ones, and indeed if $C \setminus \{i\} \cap S = A$, then $i \not\in A$, so $A \cup \{i\}$ can only be solved by some $C \in \mc{C}$. Yet if there existed such a $C \in \mc{C}$, then $C \setminus \{i\} \cap S = A$, so $C \setminus \{i\} \not\in \mc{C}$, so thus $C \not\in \pi_i(\mc{C})$. \\

      With this as such, we see that the fully compressed system $\mc{A}$ is a down-set, and thus has VC dimension equal to the highest cardinality set it contains. If $\mc{C}$ has VC dimension $\le d$, thus the largest element $\mc{A}$ can contain has cardinality $d$, so $|\mc{A}| \le |[n]^{(\le d)}|$. \\

      Note that as $\mc{A}$ shattering $S$ requires that $2^{|S|} = |\restr{\mc{A}}{S}| \le |\mc{A}|$, we get $\mathrm{VC}(\mc{A}) \le \log |\mc{A}|$. Furthermore, with the (loose) bound of $\sum_{k = 0}^d {n \choose k} \le n^{d+1}$, we are able to get
      \begin{align*}
        \frac{\log |\mc{A}|}{\log n} - 1\le \mathrm{VC}(\mc{A}) \le \log |\mc{A}|.
      \end{align*}
      and thus $\mathrm{VC}(\mc{A}) = \Theta(\log |\mc{A}|)$.
      }

\block{Combinatorial Nullstellensatz}{
    \begin{theorem}[Combinatorial Nullstellensatz]
      \ Let $\mathbb{F}$ be a field, $f \in \mathbb{F}[x_1, \dots, x_n]$ a polynomial of degree $t$, with $t_1, \dots, t_n$ such that $\sum_{i=1}^n t_i = t$ and $\prod_{i=1}^n x_i^{t_i}$ has non-zero coefficient in $f$. \\

      If there are sets $S_1, \dots, S_n$ in $\mathbb{F}$ each with $|S_i| \ge t_i + 1$, then there is $\bm{s} \in \prod_{i=1}^n S_i$ such that $f(\bm{s}) \neq 0$.
    \end{theorem}
    \hphantom{}

    The proof is by induction. For $t = 1$, $f$ is linear in an argument, and the statement is immediate. Assuming that there are $S_1, \dots, S_n$ in $\mathbb{F}$ with $|S_i| \ge t_i + 1$, and taking $s_1 \in S_1$,
    \begin{align*}
      f(x_1, \dots, x_n) &= (x_1 - s_1)g(x_1, \dots, x_n) + h(x_2, \dots, x_n)
    \end{align*}
    where $g$ is a polynomial of degree $t-1$ with monomial $x_1^{t_1-1}\prod_{i=2}^nx_i^{t_i}$, and $h \in \mathbb{F}[x_2, \dots, x_n]$ with degree $t$. Immediately, for $(s_2, \dots, s_n) \in \prod_{i=2}^n S_i$, $f(s_1, s_2, \dots, s_n) = h(s_2, \dots, s_n)$. Furthermore, by the inductive hypothesis there is some $(s_1', \dots, s_n') \in (S_1 \setminus \{s_1\}) \times \prod_{i=2}^n S_i$ such that $g(s_1', \dots, s_n') \neq 0$, so
    \begin{align*}
      f(s_1', \dots, s_n') &= (s_1' - s_1)g(s_1', \dots, s_n') + h(s_2', \dots, s_n') \\
      &= (s_1' - s_1)g(s_1', \dots, s_n') + f(s_1, s_2', \dots, s_n')
    \end{align*}
    and thus $f(s_1', \dots, s_n') \neq f(s_1, s_2', \dots, s_n')$, so at least one of these is non-zero. \\

    This is naturally an incredibly wide-reaching theorem. The key idea is that given a problem, we want to construct a polynomial with informative zeros, and then take a subset of its domain big enough to guarantee a non-zero value, which indicates that we've exited our initial case. \\

    \begin{theorem}
      \ With $H_1, \dots, H_m$ a family of hyperplanes in $\mathbb{R}^n$, and
      \begin{align*}
        \left|\{0, 1\}^n \cap \bigcup_{i=1}^m H_i\right| = 2^n -1.
      \end{align*}
      Then $m \ge n$.
    \end{theorem}
    \hphantom{}

    To prove this, construct a polynomial $P(\bm{x})$ for $\bm{x} \in \mathbb{R}^n$, which is zero on $\{0, 1\}^n$ if $\bm{x}$ is contained in a hyperplane and non-zero, or equal to zero. This can be easily constructed with degree $n \lor m$, and if $m < n$, the combinatorial nullstellensatz gives us that there is $\bm{s} \in \{0,1\}^n$ such that $P(\bm{s}) \neq 0$, so thus there must be a point not contained in a hyperplane. \\

    \begin{theorem}[Cauchy-Davenport]
    \ If $p$ is prime and $A, B \subseteq \mathbb{Z}_p$, then
    \begin{align*}
      |A + B| \ge \min \{p, |A|+|B|-1\}.
    \end{align*}
    \end{theorem}
    \hphantom{}

    The claim is almost immediate for $|A|+|B| > p$, as we just need to show that $A + B = \mathbb{Z}_p$. In the case $|A| + |B| \le p$, we want to claim a contradiction if $|A+B| \le |A|+|B|-2$, by constructing a polynomial of degree $|A|+|B|-2$, zero on $A \times B$. Yet combinatorial nullstellensatz should give an element on which the polynomial is nonzero, and this gives us a contradiction.
    }
